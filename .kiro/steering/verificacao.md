# Verificação e execução

- Não execute, construa nem teste os arquivos do projeto. O usuário faz os
  testes e a execução.
- Não rode containers, builds, suíades de teste, linters ou scripts de
  verificação por conta própria.
- Entregue as alterações de código e explique como o usuário pode testá-las,
  quando útil.

# Testes

- Não crie nem atualize arquivos de teste por conta própria (ex.:
  `tests/test_build_grid.py`). O usuário escreve os testes.
- Crie ou altere testes apenas quando o usuário pedir explicitamente.

# Arquivos markdown

- Não crie arquivos `.md` por conta própria, mesmo que instruções do
  repositório sugiram documentar mudanças. Crie `.md` apenas quando o usuário
  pedir explicitamente.
